ENDPOINT  tests/harness/mock-provider, profile `hostile`, a real OS process on loopback
HONESTY   VERIFIED-BY-FAKE. The endpoint is a deterministic mock; no model produced
          any byte below. Nothing here is evidence about a real model.

  THE SHAPE DRIVEN IS FINDING 2's: a 200 whose SSE stream carries an
  `{"error":{...}}` object, read frame by frame through `BodyStream::next_chunk` —
  and, beside it, a 400 read whole. Both bindings: the credential in the query string
  (percent-encoded on the wire, DECODED by any gateway that parses it) and the
  credential in an `x-api-key` header (raw, `/` and all).
  A spelling is judged two ways, and the transcript says which applies:
  READABLE          the key, or the percent form Vela itself wrote, is in the text
  RECONSTRUCTIBLE   it is not — but one pass of ordinary decoding gets back to it
